# Corrections and contributions

Changes must identify the precise public source record and pinned revision, the field being corrected, and the expected numerical or provenance delta. Do not invent additional significant figures, silently relabel aggregate metrics as single-stream results, infer direct ANE tracing from Core ML placement, or equate the production and diagnostic LFM graphs.

These data are already publicly summarized. **Do not upload private ANE-RE code, raw fixtures, model weights, closed-provider dumps, correspondence, credentials, or other secrets.** Corrections to the independent underlying experiment must be validated in its original evidence ledger before this repository represents them as new measurements.

Submit an issue or pull request with a reproducible numerical check. Update source hashes and release metadata together if an upstream source revision changes intentionally.
