# Security policy

This is a publication of source-bound, **public** derived research summaries. It is not a service, kernel component, exploit catalog, or live model deployment.

To report accidental disclosure, an integrity defect, a malicious file, or a vulnerability affecting the verification script, contact research@macbrainslabs.org. Avoid attaching secrets or nonpublic third-party artifacts. Use a private channel for sensitive reports. This repository is not a claim of a CVE, vulnerability discovery, security audit or bug-bounty credential.

Security corrections receive a source-linked note. No particular response SLA is promised.
